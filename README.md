# 💻 🇨 Desvendando a Linguagem C: Conceitos & Exercícios

Este repositório foi criado com o objetivo de consolidar meus estudos na **Linguagem C**. Aqui, você encontrará a implementação de diversos exercícios práticos, além de anotações essenciais sobre a sintaxe, lógica de programação e conceitos estruturais da linguagem.

---

## 📌 Objetivos do Repositório

* **Fixação de Sintaxe:** Praticar a escrita correta e limpa do padrão C (ANSI C / C11).
* **Domínio de Conceitos Core:** Entender a fundo o funcionamento de ponteiros, alocação de memória e estruturas de dados.
* **Resolução de Problemas:** Exercícios focados em lógica, matemática discreta e algoritmos clássicos.

---

📝 Conceitos Fundamentais Documentados

Ao longo dos códigos, busco documentar e aplicar os seguintes pilares da linguagem:


1. Tipagem e Sintaxe Estrita

    Diferente de linguagens de alto nível, C exige precisão na definição dos tipos de dados (int, float, char, double) e no uso correto dos especificadores de formato (%d, %f, %c).


2. Controle de Fluxo e Lógica Discreta

    Implementação de estruturas de decisão e laços de repetição, aplicando conceitos de álgebra booleana para simplificação de expressões lógicas.


3. Gerenciamento de Memória

    A essência do C reside na capacidade de manipular a memória diretamente: (Aritmética de Ponteiros | Alocação Dinâmica na memória Heap.)


🛠️ Como Executar os códigos

Para compilar e rodar os códigos deste repositório, você precisará de um compilador C (como o gcc).
